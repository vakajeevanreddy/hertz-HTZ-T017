Implement an integrated clinical diagnosis assistance, automated form-retrieval, and text-analytics workflow within the AIVOA-CRM-HCP platform. Currently, healthcare professionals manually review lengthy interaction histories and repetitive administrative forms when documenting patient diagnoses, which slows clinical intake and increases the risk of overlooked documentation errors. Adding a Retrieval-Augmented Generation (RAG) pipeline and an embedded conversational assistant enables the system to evaluate incoming patient information, automatically retrieve and populate standard clinical intake forms, and condense verbose interaction logs into concise summaries using a Large Language Model (LLM).

The implementation must also provide a deterministic dry-run or local fallback mode for offline verification, structured JSON response payloads distinguishing successful retrieval, validation rejection, and fallback states, and a word-cloud error analyzer that parses raw clinical strings to surface frequent text anomalies and formatting discrepancies. Existing FastAPI endpoints, React UI routes, authentication middleware, and baseline SQLite HCP interaction schemas must retain their exact current behavior and data persistence formats. The starting source is the unchanged AIVOA-CRM-HCP repository at the pinned baseline commit and does not include these features. Checked once more against the pinned baseline before filing.
